# OpticalLab 1.1.0 — готовые материалы с дисперсией и поглощением

В справочник добавлены **SiO₂, MgF₂, TiO₂, Ta₂O₅, HfO₂, Al₂O₃, Al, Ag и Au**. Выберите материал, добавьте его в проект и назначьте слою: спектры рассчитываются по включённым формулам и численным коэффициентам, без ручного ввода и без загрузки данных из сети.

## Что изменилось

- Вкладка «Готовые материалы»: девять наборов, формулы, полные таблицы коэффициентов, источники, тип образца, диапазоны и погрешности аппроксимации.
- Предпросмотр n/κ с выбором УФ, видимого, ИК или полного диапазона.
- Причинные модели Доусона–Гаусса для шести диэлектриков и опубликованные параметры Друде–Лоренца Rakić для металлов.
- Сохранение всех параметров и источников в JSON-проекте и метаданных экспорта. Старые проекты продолжают открываться.
- Проверка диапазона без скрытой экстраполяции, корректное преобразование временного соглашения к n−iκ исходного ядра.
- Полные исходники приложения, тесты, коэффициенты и исходные CC0-данные включены в архив [OpticalLab-v1.1.0.zip](OpticalLab-v1.1.0.zip).

## Диапазоны и точность

| Материалы | Проверенный диапазон λ, мкм |
|---|---:|
| SiO₂, MgF₂, TiO₂, Ta₂O₅, HfO₂, Al₂O₃ | 0,2–25 |
| Al | 0,2066403–12,3984198 |
| Ag, Au | 0,2066403–9,9187359 |

Диэлектрические коэффициенты — **собственные численные аппроксимации опубликованных данных Franta**, а не авторские коэффициенты исходной модели. Максимальное абсолютное отклонение n и κ в проверках исходных, отложенных и межузловых точек — менее 0,003; ошибки по каждому материалу и диапазону показаны в справочнике. Это не погрешность измерений и не гарантия свойств конкретной плёнки. Пресеты не предназначены для определения ppm-потерь. SiO₂ соответствует объёмному кварцевому стеклу; остальные диэлектрики — указанным в источниках плёнкам.

Модель слоёв остаётся изотропной и когерентной. Среда падения и полубесконечная подложка должны быть прозрачными; новые поглощающие наборы предназначены для конечных слоёв. УФ и ИК за пределами таблицы не поддерживаются этими пресетами.

## Проверка

- **83 автоматических теста:** 44 исходного ядра + 39 приложения, материалов и интеграции.
- Компактные ссылки на материалы во встроенном ассистенте; восстановление точных сохранённых коэффициентов до проверки проекта.
- Независимое сравнение однослойного расчёта с формулами Френеля для всех девяти материалов в трёх диапазонах.
- Проверка пассивности, знаков, соотношений Крамерса–Кронига, опубликованных металлических констант и воспроизводимости JSON-проектов.
- Проверка шести диэлектрических моделей на исходных и отложенных данных; положительное конечное поглощение на 10001 точке каждой модели; воспроизводимая подгонка без сети.
- TypeScript и сборка интерфейса. Ручная проверка выбора материала и расчёта в браузере.

Подробности: [отчёт](VALIDATION_v1.1.0.md), [формулы и проверка диэлектриков](DIELECTRIC_FITS_RU.md), [все коэффициенты](MATERIAL_COEFFICIENTS_RU.md).

## Запуск

Скачайте **OpticalLab-v1.1.0.zip**, распакуйте и следуйте README внутри. Нужны Node.js 22.13+ и Python 3.12+. После установки зависимостей: `npm run lab`; на macOS также доступен `start.command`. Перед запуском новой версии остановите прежний экземпляр приложения.

Это локальное приложение. Релиз не создаёт интернет-сервис. API-ключ для ручного расчёта не нужен. Архив содержит исходники, справочник, исходные CC0-данные, тесты и документацию; зависимости устанавливаются отдельно. Контрольная сумма прилагается в SHA256SUMS.txt.
