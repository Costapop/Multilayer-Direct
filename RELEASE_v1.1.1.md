# OpticalLab 1.1.1 — исправление пересчёта диапазона и графиков

После сдвига или увеличения графика версия 1.1.0 могла рассчитать новый спектральный диапазон, но оставить прежние границы оси и скрыть кривые. Теперь после «Рассчитать» новый результат отображается целиком.

- Сброс масштаба после успешного расчёта, ответа ассистента и открытия сохранённого варианта.
- Отмена текущего задания при изменении расчётных параметров; поздний ответ старого задания не меняет графики, ошибки или прогресс.
- Смена нм, мкм, 1/λ и 2π/λ сохраняет физический диапазон вместо подстановки исходных значений.
- Читаемые сообщения о некорректных границах и числе точек.
- Корректные подсказки при сравнении спектров с разными диапазонами и числом точек.

Проверено **102 теста**, TypeScript, сборка и сценарии изменения диапазона в браузере. [Подробный отчёт](VALIDATION_v1.1.1.md).

Справочник девяти материалов, коэффициенты и физическое ядро сохранены. [Формулы и коэффициенты](MATERIAL_COEFFICIENTS_RU.md) · [Точность моделей](DIELECTRIC_FITS_RU.md).

Скачайте **OpticalLab-v1.1.1.zip**, распакуйте и следуйте README. Нужны Node.js 22.13+ и Python 3.12+. После установки зависимостей: `npm run lab`; на macOS также есть `start.command`. Перед запуском остановите предыдущий экземпляр. После изменения диапазона нажмите «Рассчитать».

Архив содержит полные исходники, тесты, модели и документацию; зависимости устанавливаются отдельно. Контрольная сумма приложена в SHA256SUMS.txt. Приложение работает локально, API-ключ для ручного расчёта не нужен.
