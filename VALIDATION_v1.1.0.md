# Проверка OpticalLab 1.1.0

Дата: 26 сентября 2026. Среда: macOS arm64, Python 3.12, NumPy 2.5.3, SciPy 1.18.1, Node.js 24.19.0.

## Автоматические проверки

Из каталога приложения:

```sh
.venv/bin/python -m unittest discover -s backend/vendor/multilayer_optics/tests -v
.venv/bin/python -m unittest discover -s backend/tests -v
.venv/bin/python scripts/reproduce_dielectric_fits.py
npx tsc --noEmit
npx eslint components/optics/Materials.tsx
npm run build
```

Пройдены 44 теста исходного ядра и 39 тестов приложения/справочника. Новые проверки охватывают загрузку всех девяти наборов без сети, вычисление n/κ, совпадение однослойных спектров с независимыми формулами Френеля (УФ, видимый, ИК), диапазоны, сохранение/восстановление параметров и источников, пассивность, независимый интеграл Крамерса–Кронига для Gaussian, опубликованные значения металлов и преобразование временного соглашения.

Семь тестов ссылок материалов проверяют компактность проекта для ассистента, восстановление исходных коэффициентов до валидации, сохранение разных версий одного набора и отклонение неизвестных ссылок. Проект с шестью диэлектриками передаётся в 5095 символах, результат поиска девяти материалов — в 2299; полные определения остаются на сервере и в сохраняемом проекте.

Проверка диэлектриков воспроизводит ограничения ошибок на исходных, отложенных и межузловых точках и проверяет 10001 длину волны на материал. Сравнение действующего backend с независимой реализацией формулы даёт расхождение не более 9,6×10⁻¹⁵ по комплексному показателю. Полная повторная подгонка также проверена. Таблица ошибок и условия образцов: [DIELECTRIC_FITS_RU.md](DIELECTRIC_FITS_RU.md).

Проверка TypeScript, целевой ESLint для нового справочника и production-сборка прошли. Сборщик сообщает информационное предупреждение о размере общего клиентского блока; оно не препятствует сборке. Глобальный ESLint не используется как утверждение о чистоте прежней кодовой базы.

## Проверка интерфейса

В браузере проверены открытие девяти готовых материалов, формулы и источники, добавление SiO₂ и Au в проект, выбор Au для конечного слоя, расчёт и отображение спектров; переключение видимого диапазона в предпросмотре n/κ. Для проверки использовались отдельные локальные порты, прежний запущенный экземпляр пользователя не изменялся.

## Ограничения

Свойства конкретной плёнки не измерялись. Погрешность аппроксимации опубликованной таблицы не равна экспериментальной погрешности. Готовые модели не подтверждают сверхмалые лазерные потери. Поглощающая подложка, анизотропия и некогерентные слои не добавлялись. Реальный запрос к OpenAI с API-ключом не выполнялся; интеграция проверяется с имитацией ответа.
