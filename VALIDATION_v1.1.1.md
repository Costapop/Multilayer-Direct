# Проверка OpticalLab 1.1.1

Дата: 26 сентября 2026. Проверено на macOS arm64, Python 3.12 и Node.js 24.19.0.

## Воспроизведение ошибки и исправление

В 1.1.0 расчёт 400–800 нм после сдвига графика вправо оставлял видимую ось 480–880 нм. После задания 1000–2000 нм и нажатия «Рассчитать» спектр уже содержал новые точки, но прежний масштаб отсекал кривые. В 1.1.1 принятый результат сбрасывает масштаб всех графиков. Это действует также для результатов ассистента и открытия сохранённого варианта.

Изменение параметров отменяет незавершённое задание. Его поздние результаты, ошибки и прогресс не заменяют новое состояние. Удаляется и задание, чей идентификатор пришёл уже после отмены. В историю сохраняется копия проекта до изменения.

Смена nm, um, cm^-1 и rad/um переводит границы с сохранением физического интервала вместо возврата к 400–800 нм. Обратные координаты сортируются. Некорректные границы и число точек проверяются до отправки задания.

График не использует длину первой кривой как общий предел данных. Подсказки сравниваемых кривых ищут совпадающую числовую координату на полной собственной сетке, без подстановки значения по индексу или интерполяции. Разрывы недостоверной фазы сохраняются.

## Автоматические проверки

**102 теста:** 44 исходного физического ядра, 42 backend, 16 интерфейсных модулей. Все прошли. Проверка TypeScript и production-сборка также прошли; осталось прежнее предупреждение сборщика о размере клиентского блока.

Новые регрессии проверяют последовательные задания с разными диапазонами/единицами/числом точек, уточнение сетки и неизменность прежних результатов. Спектры поглощающей плёнки независимо сверены с формулой Френеля. Кэш дисперсии и расчётное ядро не менялись: дефекта в них не обнаружено.

Тесты интерфейса покрывают отмену и гонки асинхронных запросов, преобразование координат и совместимые с Recharts 3.8 подсказки для разных сеток. Используется установленный селектор Recharts, воспроизводящий ограничение подсказок в старой реализации.

Из каталога приложения:

```sh
.venv/bin/python -m unittest discover -s backend/vendor/multilayer_optics/tests -v
.venv/bin/python -m unittest discover -s backend/tests -v
npm test
npx tsc --noEmit
npm run build
```

## Проверка в браузере

- Сдвиг графика 400–800 нм, пересчёт 1000–2000 нм с 257 точками: обе оси и кривые обновились, масштаб сброшен.
- Переход к 1–2 мкм и обратной оси 5000–10000 см⁻¹ сохраняет физический диапазон.
- Сравнение сохранённого спектра из 257 точек с новым 2–4 мкм из 9 точек: обе сетки показываются в общем диапазоне.
- Перевод 2–4 мкм в 2500–5000 см⁻¹, диагностика неверного конца 2400, успешный повторный расчёт после исправления.
- Открытие сохранённого варианта восстанавливает 1–2 мкм, 257 точек и правильный масштаб.

Реальный запрос к OpenAI не выполнялся. Формулы, коэффициенты и пределы применимости материалов совпадают с 1.1.0; см. [описание моделей](DIELECTRIC_FITS_RU.md).
