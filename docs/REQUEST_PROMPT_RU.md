**1. Результат и физическая модель**

Для каждого волнового числа на заданной сетке интервала [k1, k2] рассчитай энергетические коэффициенты Rs, Rp, Ts, Tp, комплексное эллипсометрическое отношение rho, углы Psi и Delta. Также верни комплексные амплитудные коэффициенты с явно указанной нормировкой и поглощение конечного покрытия As, Ap для контроля энергетического баланса.

Модель: плоская монохроматическая волна, N плоскопараллельных однородных изотропных немагнитных слоёв; гладкие границы; когерентное сложение волн; линейные пассивные материалы слоёв с дисперсией и поглощением. Слои бесконечны в плоскости границ. Подложка однородная, полубесконечная и непоглощающая на всём расчётном интервале; её показатель n_sub(k)>0 действительный и может иметь дисперсию. Отражение от задней поверхности подложки отсутствует. Объясни, что конечная подложка с задней поверхностью, частичная когерентность, шероховатость, анизотропия и оптическое усиление требуют расширения модели.

Внешняя среда прозрачная, с действительным положительным n0(k); по умолчанию n0=1. Это отдельный входной параметр. Поглощение разрешено только в N конечных слоях; kappa_sub(k)=0 на всём интервале. Не распространяй автоматически формулы энергетического баланса на поглощающую внешнюю среду.

**2. Входные данные и соглашения**

Опиши схему входных данных и проверки:

- N — целое число, N>=0; слой 1 ближайший к внешней среде, слой N прилегает к подложке; внешняя среда имеет индекс 0, подложка — N+1.
- d[j] — геометрическая толщина слоя, d[j]>=0, с явно заданной единицей длины.
- Комплексные показатели каждого конечного слоя и действительный положительный показатель подложки как функции спектральной координаты, таблицы либо постоянные значения. Проверяй отсутствие поглощения в подложке на всём заданном интервале; ненулевую физическую мнимую часть входного n_sub отклоняй с понятной ошибкой, а не отбрасывай молча.
- Угол theta0 относительно нормали: 0<=theta0<90 градусов; единица угла задаётся явно, внутри расчёта используются радианы. Угол фиксирован на всём интервале.
- 0<k1<k2 и явная сетка либо число точек M>=2/шаг построения сетки. Оба конца интервала включены. Укажи поведение при некорректных, повторяющихся и неупорядоченных узлах.

Сохрани временное соглашение книги: exp(+i*omega*t), комплексный показатель слоя n_tilde=n-i*kappa, n>=0, kappa>=0 для принятой модели пассивных немагнитных материалов; проверь Im(epsilon)<=0. Для подложки n_tilde[N+1]=n_sub(k)>0 и epsilon[N+1]=n_sub(k)^2 действительны. Не путай коэффициент экстинкции kappa с волновым числом k. Для таблиц слоёв, записанных как n+i*kappa, требуй явного указания исходного соглашения и преобразуй данные на входе.

В книге k=omega/c=2*pi/lambda_vac. Отличи это от спектроскопического волнового числа nu_bar=1/lambda_vac. Предусмотри явный параметр типа спектральной координаты и преобразование k=2*pi*nu_bar. Не определяй смысл координаты только по единице «см^-1». Все фазовые множители должны быть безразмерными; покажи преобразования единиц для толщин в нм и волновых чисел в см^-1.

Задай ось z внутрь покрытия, плоскость падения xz, s-направление вдоль +y. Объясни отличие от ориентации оси и нумерации слоёв в книге. Укажи плоскости отсчёта амплитуд: r на входной границе покрытия, t между входной границей и границей с подложкой.

**4. Продольная компонента и оптические адмиттансы**

Для каждого k введи:

```text
alpha=n0(k)*sin(theta0),
epsilon[j]=n_tilde[j]^2,
q[j]=sqrt(epsilon[j]-alpha^2),
phi[j]=k*q[j]*d[j].
```

Здесь k*q[j] — продольная компонента волнового вектора. Не вычисляй комплексные углы через arcsin, если достаточно q[j]. Ветвь корня должна соответствовать затуханию волны в направлении подложки: Im(q[j])<=0; для действительного корня выбери Re(q[j])>=0. Обоснуй правило для выбранного временного соглашения, распространяющихся и эванесцентных волн. Опиши допуски около действительной оси, не превращающие слабое поглощение в усиление. Действительный показатель подложки не гарантирует действительный q[N+1]: при alpha>n_sub возникает эванесцентная волна с чисто мнимым q[N+1], что не является поглощением материала.

Для касательных электрических амплитуд используй нормированные адмиттансы:

```text
Y_s[j]=q[j],
Y_p[j]=epsilon[j]/q[j].
```

Объясни их связь с n_tilde*cos(theta) и n_tilde/cos(theta), а также связь с потоком энергии. Символ q здесь не равен поляризационно зависимому q книги для обеих поляризаций: отрази это в таблице обозначений.

**5. Основной устойчивый алгоритм**

Выведи из (1.2.18) рекурсию, использующую только затухающие множители u[j]=exp(-i*phi[j]), |u[j]|<=1. Прямое перемножение обычных характеристических матриц не должно быть единственным рабочим методом: при большом N, сильном поглощении и толстых эванесцентных слоях оно может терять точность и переполняться.

Для каждой поляризации отдельно введи интерфейсные коэффициенты касательных электрических амплитуд:

```text
f[a,b]=(Y[a]-Y[b])/(Y[a]+Y[b]),
g[a,b]=2*Y[a]/(Y[a]+Y[b]).
```

Обозначь b[j] и tau[j] эффективные коэффициенты отражения и пропускания оставшейся структуры при падении из среды j. Инициализация на границе с подложкой:

```text
b[N]=f[N,N+1],
tau[N]=g[N,N+1].
```

Для j=N-1,...,0 используй:

```text
D[j]=1+f[j,j+1]*b[j+1]*u[j+1]^2,
b[j]=(f[j,j+1]+b[j+1]*u[j+1]^2)/D[j],
tau[j]=g[j,j+1]*u[j+1]*tau[j+1]/D[j].
```

Результат: r_tan=b[0], t_tan=tau[0]. При N=0 инициализация должна сразу давать единственную границу внешняя среда/подложка. Покажи происхождение каждого множителя и порядок обновления переменных. Не используй обозначение R для промежуточных комплексных амплитуд.

Проверь приведённые соотношения выводом из граничных условий и книги; обнаруженные несоответствия исправляй с объяснением. Допустима эквивалентная устойчивая S-матрица, если показаны соответствие формулам и преимущества выбора.

Предусмотри:

- Нулевые толщины, совпадающие материалы, большие N, почти скользящее падение, малые знаменатели около резонансов.
- Точное q[j]=0 и окрестность критического угла: обычная рекурсия может дать 0/0, а Y_p расходится. Выведи согласованный предельный блок слоя, например через sin(k*q*d)/q -> k*d. Для q[N+1]=0 на точном критическом угле прозрачной подложки вычисляй T согласованным пределом T=0, исключив произведение бесконечного Y_p на нулевое |t_tan_p|^2. Нельзя просто заменить нулевой q произвольным epsilon. Особые случаи epsilon[j]=0 также должны иметь явную обработку или обоснованный диагностический статус.
- Очень малое пропускание: масштабирование либо накопление log|t| с фазой, при необходимости log(T). Отличай физическое T=0 от потери представимости положительного значения. Не ограничивай искусственно оптическую толщину для удобства вычисления.
- Отсутствие переполнения экспонент и контроль точности фаз при больших оптических толщинах. Не заявляй абсолютную устойчивость при любых входных данных без указания границ численной точности.

Матрицы книги оставь вторым, проверочным методом для умеренных оптических толщин. Явно выведи порядок их произведения при выбранной нумерации.

**6. Энергетические коэффициенты**

Из нормальной компоненты усреднённого вектора Пойнтинга выведи для sigma=s,p:

```text
R_sigma=|r_tan_sigma|^2,
T_sigma=Re(Y_sigma[N+1])/Re(Y_sigma[0])*|t_tan_sigma|^2,
A_coating_sigma=1-R_sigma-T_sigma.
```

Объясни, почему T обычно не равно |t|^2. Для распространяющейся волны в прозрачной подложке её адмиттанс действителен и допустимо упрощение до отношения действительных адмиттансов. Однако при эванесцентной волне Y_sub чисто мнимый и T=0: нельзя непосредственно использовать комплексное отношение Y_sub/Y_0 вместо отношения действительных частей. Поэтому сохрани общее выражение (1.1.23), а упрощённую запись T=(q_s/q_a)|t|^2 применяй только в пределах её применимости.

Для непоглощающей полубесконечной подложки T означает нормальный поток энергии, переданный в неё; для распространяющейся волны он сохраняется с глубиной. A_coating относится только к N конечным слоям. Для N=0 имеем A_coating=0 и R+T=1. При эванесцентной волне в подложке T=0; если конечные слои поглощают, R может быть меньше 1 и A_coating=1-R. Условие R=1 в этом случае требует отсутствия поглощения в покрытии.

Не подменяй малые нарушения баланса принудительным обрезанием R,T,A до [0,1]. Сохраняй исходные значения, оценивай погрешность и возвращай диагностику. Если A вычислено разностью, тождество R+T+A=1 само по себе не является независимой проверкой.

**7. Эллипсометрия и фазовые соглашения**

Задай p-базисы явно: e_p,in=(cos(theta0),0,-sin(theta0)), e_p,refl=(-cos(theta0),0,-sin(theta0)); e_s,in=e_s,refl=(0,1,0). При таком выборе:

```text
r_s=r_tan_s,
r_p=-r_tan_p,
rho=r_p/r_s=tan(Psi)*exp(i*Delta).
```

Объясни, что смена знака только отражённого p-базиса при неизменном падающем сдвигает Delta на 180 градусов, сохраняя Rs,Rp,Ts,Tp,Psi. Поэтому значения фаз нельзя сравнивать между программами без сопоставления соглашений. Не называй выбранное соглашение единственно возможным.

Вычисляй Psi=atan2(|r_p|,|r_s|), 0<=Psi<=pi/2. Для Delta используй устойчивое вычисление разности фаз либо arg(r_p*conj(r_s)) с защитой от потери представимости; основной диапазон 0<=Delta<2*pi. Верни радианы и явно обозначенные градусы. Развёрнутую фазу разреши отдельным выходом только на непрерывных участках достоверных данных.

Обработай r_s=0, r_p=0, оба коэффициента равны нулю и их малые значения. При r_s=0 отношение rho сингулярно; при нуле любой компоненты Delta не определена; при обоих нулях Psi тоже не определена. Используй маски достоверности и понятные статусы, а не произвольную нулевую фазу. Задай настраиваемые критерии для почти нулевых амплитуд.

При нормальном падении и ненулевом отражении проверь Rs=Rp, Ts=Tp, r_p=-r_s, Psi=45 градусов, Delta=180 градусов в заданном базисе. Отметь вырождение выбора плоскости падения при theta0=0.

Опиши экспорт в соглашение exp(-i*omega*t), n+i*kappa: комплексные амплитуды и rho сопрягаются, R,T,Psi сохраняются, Delta меняет знак по модулю 2*pi. Определение rho и ориентации базисов при этом сохраняются.

Для дополнительной проверки потоков и фазовых соглашений можно использовать первичный источник S. J. Byrnes, «Multilayer optical calculations», §§2.2, 4.4, 5 и приложение A: [текст статьи](https://arxiv.org/html/1603.02720v5). У него иное временное соглашение, а определение Delta в §4.2 содержит дополнительный минус; не переноси его формулу Delta автоматически в заданный здесь контракт.
