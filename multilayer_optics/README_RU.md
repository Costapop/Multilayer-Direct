# Расчёт многослойного оптического покрытия

Пакет рассчитывает спектры энергетических коэффициентов Rₛ, Rₚ, Tₛ, Tₚ, поглощение конечных слоёв Aₛ, Aₚ, комплексные амплитуды, эллипсометрическое отношение ρ и углы Ψ, Δ. Подложка **однородная, полубесконечная и непоглощающая**, с допустимой действительной дисперсией. Поглощение и дисперсия допускаются в конечных слоях. Показатель внешней среды также может зависеть от спектральной координаты, но должен быть действительным положительным.

Это расчётное ядро с документацией и проверками. Оно отделено от интерфейса приложения, чтения справочников материалов и построения графиков.

## Минимальный пример для приложения

```python
from multilayer_optics import Layer, make_grid, calculate_spectrum

layers = [
    Layer(material=2.05-0.02j, thickness=80, unit="nm", name="Слой 1"),
    Layer(material=1.45, thickness=110, unit="nm", name="Слой 2"),
]

result = calculate_spectrum(
    coordinate=make_grid(12500, 25000, 501),
    kind="spectroscopic_wavenumber",  # 1/lambda_vac, а не 2*pi/lambda_vac
    unit="cm^-1",
    layers=layers,
    substrate=1.52,
    ambient=1.0,
    theta=60.0,
    angle_unit="deg",
)

values = result.arrays()
Rs, Tp = values["Rs"], values["Tp"]
psi, delta = values["psi_deg"], values["delta_deg"]
delta_valid = values["delta_valid"]
result.write_json("spectrum.json")
```

Материалы этого фрагмента синтетические. Их не следует интерпретировать как справочные константы конкретных веществ.

Низкоуровневый вызов одной точки:

```python
from multilayer_optics import solve_point

p = solve_point(
    k=10.0,                  # rad/um, k=2*pi/lambda_vac
    indices=[2.05-0.02j, 1.45],
    thickness_um=[0.08, 0.11],
    substrate=1.52,
    theta=60.0,
)
print(p.s.R, p.p.T, p.psi_deg, p.delta_deg)
print(p.diagnostics)
```

## Материалы и дисперсия

Материал задаётся одним из трёх способов:

1. Комплексная или действительная константа.
2. Функция `material(k_array)`, получающая NumPy-массив k в rad/um и возвращающая скаляр либо массив той же формы.
3. `TabulatedMaterial` со строго возрастающей собственной спектральной координатой.

```python
import numpy as np
from multilayer_optics import Layer, TabulatedMaterial

def model_index(k):
    wavelength_um = 2*np.pi/k
    return 1.8 + 0.01/wavelength_um**2 - 0.02j

layer = Layer(model_index, 100, "nm")

table = TabulatedMaterial(
    x=[400, 500, 650, 800],
    values=[2.1+0.05j, 2.0+0.04j, 1.9+0.03j, 1.85+0.02j],
    kind="wavelength", unit="nm", convention="n_plus_ik",
)
layer_from_table = Layer(table, 80, "nm")
```

Последний пример явно преобразует табличное n + iκ во внутреннее n − iκ. Для `TabulatedMaterial` соглашение задаётся в её конструкторе; повторно указывать `n_plus_ik` в `Layer` нельзя. Для константы или функции это соглашение задаётся в `Layer(..., convention="n_plus_ik")`.

Интерполяция линейная отдельно для n и κ, **в собственной координате таблицы**. Она сохраняет неотрицательность исходных n и κ, но сама по себе не доказывает причинность/Kramers–Kronig или физическую точность данных. Экстраполяция запрещена. Концы таблицы разрешены; выход за диапазон в k, даже на один представимый шаг, отклоняется.

Для таблицы подложки проверяются все исходные значения: n > 0 и Im n = 0. Линейная интерполяция сохраняет прозрачность. Для произвольной функции проверяются только запрошенные узлы; гарантировать её свойства между ними должен поставщик данных. Мнимая часть показателя подложки никогда не отбрасывается молча.

## Контракт входов

| Параметр | Тип и ограничения |
|---|---|
| `coordinate` | Массив `(M,)`, M>=2, конечные положительные строго возрастающие значения без повторов |
| `kind` | `angular_wavenumber` = 2π/λ; `spectroscopic_wavenumber` = 1/λ; `wavelength` = λ |
| `unit` | `nm`, `um`, `mm`, `cm`, `m` для длины волны; обратные единицы для волнового числа, например `cm^-1`; `rad/um` допускается для углового числа |
| `layers` | Последовательность `Layer`, допускается пустая; порядок от источника к подложке |
| `Layer.thickness` | Скаляр >=0; конечный; геометрическая толщина в `Layer.unit` |
| `substrate`, `ambient` | Материалы строго действительные >0; полубесконечные; по умолчанию `ambient=1` |
| `theta`, `angle_unit` | Скалярный угол от нормали, `deg` или `rad`, 0 ≤ θ < 90° (или 0 ≤ θ < π/2 в радианах) |
| `config` | `SolverConfig` с допусками; см. ниже |
| `chunk_size` | Положительное целое; по умолчанию 256 спектральных точек в блоке |

Неправильный порядок узлов не исправляется сортировкой. Возрастающая длина волны преобразуется в убывающий внутренний k, и это допустимо: выход сохраняет исходный порядок. Функция `make_grid(start, stop, count)` включает оба конца и проверяет возможность разместить все узлы в float64. Количество слоёв N определяется длиной `layers`, а не отдельным потенциально противоречивым полем.

Толщина ноль означает отсутствие слоя. Материал всё равно должен быть корректным входным материалом; физический расчёт удаляет такой слой до операций с его адмиттансом.

Низкоуровневое `solve_point` использует уже преобразованные **показатели в одной точке**, k в rad/um и массив толщин в um. Оно не выполняет интерполяцию материалов и не выбирает единицы автоматически.

## Контракт выходов

`SpectrumResult.arrays()` возвращает словарь массивов `(M,)`. Все энергетические коэффициенты — **доли, не проценты**.

| Поля | Значение |
|---|---|
| `coordinate`, `k_rad_per_um`, `lambda_um` | Исходная координата и две внутренние спектральные характеристики |
| `Rs`, `Rp`, `Ts`, `Tp`, `As`, `Ap` | Энергетические коэффициенты и поглощение только конечных слоёв |
| `r_tan_s`, `r_tan_p`, `t_tan_s`, `t_tan_p` | Комплексные отношения касательных электрических амплитуд |
| `r_s`, `r_p`, `rho` | Амплитуды в заданных векторных базисах и ρ = rₚ/rₛ |
| `psi_rad`, `psi_deg`, `delta_rad`, `delta_deg` | Эллипсометрические углы; Ψ ∈ [0°, 90°], Δ ∈ [0°, 360°) |
| `rho_valid`, `psi_valid`, `delta_valid` | Маски определённости/достоверности около нулей отражённых компонент |
| `delta_unwrapped_rad` | Развёрнутая фаза только внутри отдельных непрерывных достоверных участков |
| `valid_s`, `valid_p` | Успешность вычисления поляризации; предупреждения дополнительно находятся в `diagnostics` |
| `log_abs_t_s/p`, `phase_t_s/p`, `log_T_s/p` | Натуральные логарифмы и фаза передачи для очень малых величин |
| `transmission_status_s/p` | `propagating`, `zero_normal_flux`, `power_underflow` или `invalid` |

`PointResult` содержит те же величины для одной точки; энергетические и касательные амплитудные результаты находятся в `.s` и `.p`. Список `diagnostics` привязан к конкретной спектральной точке; сообщения могут содержать поляризацию и исходный номер слоя.

`write_json` записывает комплексное число как `{ "re": ..., "im": ... }`. Неопределённые или непредставимые специальные значения — `null`, с масками и статусами рядом. Экспорт никогда не содержит невалидные JSON-токены `NaN`/`Infinity`.

При физическом нулевом нормальном потоке в подложку `T=0`, `log_T=-inf` внутри Python, `null` в JSON и статус `zero_normal_flux`. При слишком малом **положительном** пропускании `T=0` из-за underflow, но `log_T` конечен и статус равен `power_underflow`. Если касательная амплитуда передачи физически нулевая, её фаза неопределена. При численном обнулении амплитуды конечные `log_abs_t` и фаза могут сохраняться.

Метаданные включают соглашения времени/показателя, порядок слоёв, толщины, плоскости отсчёта, тип координаты, единицы и допуски. Они должны сохраняться вместе со спектром при передаче в приложение.

## Знаки и физический смысл

Временное соглашение книги: exp(+iωt). Для пассивного слоя ñ = n − iκ. Вектор отражённой p-поляризации выбран так, что `r_p = -r_tan_p`, а `r_s = r_tan_s`. Поэтому при нормальном падении и ненулевом отражении Ψ = 45°, Δ = 180°. Это условие выбора базиса, а не универсальное соглашение всех приборов.

```python
minus_time = result.arrays(time_convention="exp(-iwt)")
result.write_json("spectrum_minus_time.json", time_convention="exp(-iwt)")
```

Переход сопрягает комплексные амплитуды и ρ, меняет знак Δ по модулю 2π, сохраняет энергии и Ψ. Он не меняет ориентацию p-базиса. Внешнюю программу или прибор нужно сопоставлять по обоим соглашениям.

В s/p касательной нормировке применяется единая формула

\[
R_σ=|r_{\rm tan,σ}|^2,\qquad
T_σ=\frac{\operatorname{Re}Y_{\rm sub,σ}}{Y_{0,σ}}|t_{\rm tan,σ}|^2,\qquad
A_σ=1-R_σ-T_σ.
\]

При эванесцентной волне в прозрачной подложке T = 0. Если конечные слои поглощают, R может быть меньше 1. Для полностью прозрачной структуры R + T = 1. Равенство R + T + A = 1, когда A определено разностью, не является независимым тестом; поэтому включена отдельная проверка интегралом объёмных потерь.

## Почему реализация отличается от буквального перемножения матриц

Матрицы книги содержат одновременно растущие и затухающие экспоненты. Рабочий метод преобразует каждый слой в масштабированный блок рассеяния относительно одного действительного фиктивного портового адмиттанса `Y_ref = Y0`. Каскад блоков эквивалентен исходным граничным условиям и использует u = exp(−iφ), |u| ≤ 1, а также логарифм передачи.

Это также позволяет вычислить аналитический предел конечного слоя с q = 0, когда обычные интерфейсные коэффициенты дают 0/0. Фиктивные порты не добавляют физических слоёв и не меняют поляризационную нормировку. Полный вывод, формулы блоков и псевдокод находятся в [теоретическом документе](THEORY_RU.md).

`matrix_reference` — отдельная реализация матриц книги для проверки хорошо обусловленных примеров. Она не используется как скрытый путь основного расчёта и отклоняет слой с |Im φ| > 20. Небольшая толщина отдельных слоёв ещё не гарантирует хорошую обусловленность длинного произведения; функция не предназначена для расчёта произвольного большого стека.

## Допуски и диагностика

| `SolverConfig` | Значение по умолчанию | Назначение |
|---|---:|---|
| `ellipsometry_atol` | 1e-12 | Порог модуля отражённой амплитуды для масок; не порог отражённой энергии |
| `energy_tol` | 2e-10 | Диагностика нарушения пассивности; значения не обрезаются |
| `denominator_rtol` | 1e-12 | Малость знаменателя относительно суммы модулей его слагаемых |
| `critical_roundoff_factor` | 8 | Оценка неразрешимого остатка прозрачного q²; 0 отключает обработку |
| `phase_error_tol` | 1e-7 rad | Порог предупреждения об ошибке аргумента очень большой фазы |

При |q²| в пределах оценки округления применяется критический предел с сообщением `CRITICAL_ROUNDOFF`. Это относится только к строго прозрачному материалу. Слабое поглощение не превращается в ноль. Для различения сторон критического угла при столь малом остатке нужны более точные исходные данные и повышенная точность арифметики.

| Код | Действие приложения |
|---|---|
| `CRITICAL_ROUNDOFF` | Показать, что использован численно неразрешимый критический предел |
| `PHASE_PRECISION` | Не полагаться на малые различия фаз; уменьшить масштаб задачи или пересчитать в повышенной точности |
| `SMALL_DENOMINATOR` | Проверить узкий резонанс и численную обусловленность |
| `ENERGY_BALANCE` | Не скрывать нарушение пассивности; проверить данные и точность |
| `AMPLITUDE_UNDERFLOW` | Использовать сохранённые `log_abs_t` и фазу вместо нулевой амплитуды |
| `POWER_UNDERFLOW` | Использовать `log_T`; не трактовать нулевое машинное T как физическое отсутствие передачи |
| `UNSUPPORTED_ENZ` | p-канал при точно ε = 0, ненулевой толщине и ненормальном падении не рассчитан |
| `NUMERICAL_FAILURE` | Численный расчёт не выполнен; соответствующий `valid=False`. При сбое общего вычисления q² или других предварительных величин недостоверны оба канала |
| `ELLIPSOMETRY_UNDEFINED` | Скрыть недостоверную Δ по маске, не заменяя нулём |

Ошибки входных данных вызывают `ValueError`; собственные исключения функций материалов передаются вызывающему коду. Поддерживаемые точные критические пределы не считаются ошибкой. Численные сбои возвращаются как `NUMERICAL_FAILURE` с `valid=False` для затронутой поляризации. Если сбой возникает при общем вычислении q² или других предварительных величин, недостоверными помечаются оба канала. Такие значения приложение не должно показывать как рассчитанный спектр. Код не обещает произвольной точности при любых числах float64.

## Контроль спектрального разрешения

```python
from multilayer_optics import refine_spectrum

check = refine_spectrum(
    make_grid(12500, 25000, 101), layers, 1.52, 60,
    kind="spectroscopic_wavenumber", unit="cm^-1",
    max_rounds=6, max_points=12801,
    atol=1e-5, rtol=1e-4, phase_atol_rad=0.02,
)
print(check.converged, check.normalized_error, check.reason)
```

На каждом раунде во все интервалы вставляются середины. Значения в серединах сравниваются с предсказанием по концам: для энергий и комплексных отражений применяется `atol+rtol*scale`, для Δ — угловая ошибка на единичном круге. Обёрнутая фаза не интерполируется как обычное число через 360/0 градусов. Проверка не объединяет участки неопределённой фазы.

`converged=True` означает выполнение этого критерия, **не математическую гарантию отсутствия пропущенных узких резонансов**. При исчерпании бюджета возвращается рассчитанный спектр и `converged=False` с причиной. Исходную сетку следует выбирать с учётом оптической толщины, ожидаемых резонансов и разрешения измерительного прибора.

## Сложность и интеграция

Физическое ядро требует O(N) операций на узел; спектр — O(NM), плюс стоимость моделей/таблиц материалов. Блочное вычисление хранит O(NB) временных индексов при размере блока B. `calculate_spectrum` дополнительно хранит O(M) выходов; `stream_spectrum` позволяет забирать точки по мере готовности. Исходная сетка и её преобразование всё равно занимают O(M). Вызов произвольной функции материала может иметь собственные затраты.

Пакет не обращается к сети во время расчёта и не имеет глобального изменяемого состояния расчётного ядра. Для параллельного вычисления независимых спектров приложение может использовать отдельные процессы; вызываемые функции материалов также должны быть безопасны для выбранного режима.

Перед использованием в приложении сохраните рядом с результатом исходную структуру, версии таблиц материалов, метаданные и диагностические сообщения. Эталон здесь использует float64/complex128; высокоточная арифметика не реализована. Её следует добавить отдельно для задач, где диагностика показывает потерю точности, и сравнивать комплексные амплитуды, не только энергии.
