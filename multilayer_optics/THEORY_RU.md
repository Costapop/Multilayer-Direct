## 2. Физическая модель

Плоская монохроматическая волна падает из прозрачной внешней среды на последовательность \(N\) плоскопараллельных слоёв, за которыми расположена прозрачная полубесконечная подложка. Все среды изотропны, линейны и немагнитны, \(\mu_r=1\). Каждый слой однороден по пространству, но его комплексный показатель может зависеть от спектральной координаты. Границы гладкие, бесконечные и параллельные. Волны складываются когерентно.

Нумерация в алгоритме:

\[
\text{внешняя среда }0\;|\;1\;|\;2\;|\;\cdots\;|\;N\;|\;N+1\text{ подложка}.
\]

Слой 1 обращён к источнику. Ось \(z\) направлена от внешней среды в подложку; входная поверхность имеет \(z=0\), выходная поверхность покрытия \(z=L=\sum_jd_j\). Плоскость падения — \(xz\), направление s-поляризации — \(+y\). Угол \(\theta_0\) измеряется от нормали и фиксирован по спектру: \(0\leq\theta_0<\pi/2\).

\[
\widetilde n_j(k)=n_j(k)-i\kappa_j(k),\qquad
n_j\geq0,\quad\kappa_j\geq0,\quad 1\leq j\leq N,
\]

\[
n_0(k)>0,\quad n_{N+1}(k)=n_{\rm sub}(k)>0,\qquad
\kappa_0=\kappa_{N+1}=0.
\]

Поглощение разрешено только в конечных слоях покрытия. Дисперсия разрешена во всех средах. Условие пассивности в принятом временном соглашении: \(\operatorname{Im}\varepsilon_j\leq0\), где \(\varepsilon_j=\widetilde n_j^2\). Для модели \(n-i\kappa\) оно следует из \(\operatorname{Im}\varepsilon=-2n\kappa\leq0\), но проверяется отдельно после преобразования входных данных.

Слой с \(d_j=0\) физически отсутствует; его удаляют до операций, содержащих деление на его \(q_j\) или \(\varepsilon_j\). Случай \(N=0\) означает единственную границу внешняя среда/подложка.

Модель не включает заднюю поверхность подложки, рассеяние на шероховатости, конечный размер пучка, частичную когерентность, анизотропию, магнитные среды, нелинейность и усиление. В частности, комплексное скалярное \(n\) не заменяет тензорную задачу анизотропного слоя. Для конечной подложки требуется задать её толщину, выходную среду и правило когерентного или некогерентного сложения.

## 3. Обозначения, единицы и плоскости отсчёта

| Здесь | В книге | Определение и единицы |
|---|---|---|
| \(N\) | \(m\) | Число конечных слоёв |
| \(j=1,\ldots,N\) | \(m+1-j\) | Здесь слои нумеруются от внешней среды; в книге — от подложки, с. 23 |
| \(n_0,n_{\rm sub}\) | \(n_a,n_s\) | Показатели внешней среды и подложки, безразмерные |
| \(\theta_0\) | \(\gamma_a\) | Угол падения относительно нормали |
| \(z\) | Ось направлена противоположно | Здесь \(+z\) направлено в подложку; в книге — из подложки во внешнюю среду |
| Плоскость \(xz\), s вдоль \(y\) | Плоскость \(yz\), s вдоль \(x\) | Отличие имён поперечных осей, с. 7 |
| \(\alpha=n_0\sin\theta_0\) | \(\alpha\) | Сохраняющаяся поперечная компонента волнового вектора, делённая на \(k\), безразмерная |
| \(q_j=\sqrt{\varepsilon_j-\alpha^2}\) | \(\widetilde n_j\cos\gamma_j\) | Продольная компонента волнового вектора, делённая на \(k\), безразмерная; одинакова для s и p |
| \(Y_{s,j}=q_j\) | \(q_j\) в S-case | Нормированный адмиттанс s-поляризации |
| \(Y_{p,j}=\varepsilon_j/q_j\) | \(q_j\) в P-case | Нормированный адмиттанс p-поляризации; **не равен** нашему \(q_j\) |
| \(\phi_j=kq_jd_j\) | \(\varphi_j\) | Комплексная фазовая толщина, безразмерная |
| \(r_{\rm tan},t_{\rm tan}\) | \(r,t\) | Отношения касательных электрических амплитуд |
| \(r_s,r_p\) | Нет соответствующего эллипсометрического определения в рассматриваемых разделах | Отражение в выбранных векторных базисах, § 10 ниже |
| \(k\) | \(k\) | Угловое вакуумное волновое число \(2\pi/\lambda_{\rm vac}\), единица обратной длины |
| \(\bar\nu\) | Не используется здесь как основной параметр книги | Спектроскопическое волновое число \(1/\lambda_{\rm vac}\), единица обратной длины |

Названия \(q_s\) и \(q_a\) книги обозначают адмиттансы подложки и внешней среды для выбранной поляризации; индекс \(s\) в \(q_s\) означает *substrate*, а не s-поляризацию.

Поле каждой поляризации нормируется так, чтобы падающая **касательная электрическая амплитуда** на \(z=0\) была равна 1. \(r_{\rm tan}\) — отражённая касательная амплитуда на той же поверхности. \(t_{\rm tan}\) — переданная касательная амплитуда на \(z=L\), делённая на падающую амплитуду на \(z=0\). Поэтому фаза пропускания включает распространение через все слои. Фазы нельзя сравнивать с программой, использующей другие плоскости отсчёта, без их переноса.

Все формулы инвариантны к выбору согласованных единиц длины. Эталонное ядро использует толщины в мкм и \(k\) в рад/мкм; радиан здесь безразмерен. Для толщины в нм и координаты в \({\rm cm}^{-1}\):

\[
d_{\rm \mu m}=10^{-3}d_{\rm nm},\qquad
k_{\rm \mu m^{-1}}=10^{-4}\,k_{\rm cm^{-1}},\qquad
\phi=10^{-7}k_{\rm cm^{-1}}q\,d_{\rm nm}.
\]

Если координата — \(\bar\nu\), а не \(k\), то

\[
k=2\pi\bar\nu,\qquad
\phi=2\pi\,10^{-7}\bar\nu_{\rm cm^{-1}}q\,d_{\rm nm}.
\]

Одной единицы «см⁻¹» недостаточно для выбора смысла координаты. Тип координаты должен храниться явно. Волновая длина в результате всегда вакуумная: \(\lambda_{\rm vac}=2\pi/k\).

## 4. Продольная компонента, ветвь корня и поля

При соглашении \(e^{+i\omega t}\) волна, уходящая в подложку, имеет пространственный множитель

\[
e^{-ik(\alpha x+q_jz)}.
\]

Для каждого спектрального узла независимо вычисляют

\[
\alpha=n_0\sin\theta_0,\qquad
q_j^2=\varepsilon_j-\alpha^2,\qquad
q_j=\sqrt{\varepsilon_j-\alpha^2}.
\]

Условие затухания с увеличением \(z\) выбирает \(\operatorname{Im}q_j\leq0\), поскольку

\[
|e^{-ikq_jd}|=e^{k d\operatorname{Im}q_j}\leq1.
\]

Для действительного корня выбирают \(\operatorname{Re}q_j\geq0\). Для \(q_j^2<0\), действительного, физическая ветвь имеет вид \(q_j=-i\sqrt{\alpha^2-\varepsilon_j}\). Она описывает затухающее эванесцентное поле даже в непоглощающем материале.

Следовательно, у прозрачной подложки возможны три режима:

| Условие | \(q_{\rm sub}\) | Нормальный переданный поток |
|---|---|---|
| \(\alpha<n_{\rm sub}\) | Положительный действительный | Обычно ненулевой |
| \(\alpha=n_{\rm sub}\) | Ноль, критический предел | Ноль |
| \(\alpha>n_{\rm sub}\) | Отрицательный чисто мнимый | Ноль |

Мнимая часть \(q_{\rm sub}\) в последней строке не означает поглощение подложки.

Не следует вычислять комплексные углы через \(\arcsin\): они не нужны для ядра и вводят дополнительные ветви. Для прозрачной падающей среды предпочтительно считать \(q_0=n_0\cos\theta_0>0\) прямо, а не вычитанием \(n_0^2-\alpha^2\), которое теряет точность при почти скользящем падении.

Для ветви корня физическое слабое поглощение не округляют к нулю. Допуски применяют к диагностике входных ошибок и округления, а не к произвольному изменению знака затухания. При необходимости корень меняют целиком на противоположный; изменение отдельно его мнимой части разрушает равенство \(q^2=\varepsilon-\alpha^2\). Сам по себе малый ненулевой \(q\) не разрешает заменять его произвольным положительным числом.

В рабочем ядре \(q^2\) можно вычислить двумя алгебраически равными способами:

\[
q^2=\widetilde n^2-\alpha^2
=(\widetilde n-n_0)(\widetilde n+n_0)+q_0^2.
\]

Выбирается выражение с меньшей суммой модулей его слагаемых, как простой оценкой абсолютной ошибки округления. Оно, в частности, помогает не потерять \(q_0^2\) у слоя, совпадающего с внешней средой, при почти скользящем падении. Напротив, для \(\widetilde n=0\) и малого ненулевого угла прямая форма сохраняет физическое \(-\alpha^2\).

Только для строго прозрачных входных данных знак остатка в пределах ошибки вычитания может быть неразрешим численно. Допустим явно задокументированный режим: если \(|q^2|\leq c\,\epsilon_{\rm mach}S\), где \(S\) — выбранная сумма модулей слагаемых, использовать критический предел и вернуть статус `critical_roundoff`. В эталонном ядре применяется \(c=8\); настройка \(c=0\) отключает такое округление. Это ограниченное решение для неразрешимого остатка, а не изменение достоверного малого поглощения и не подстановка произвольного epsilon в знаменатель. Для выяснения режима конкретной физической точки требуется повышенная точность исходных данных и арифметики.

Удобно ввести обобщённое касательное магнитное поле \(h\): для s-поляризации \(h=-Z_0H_x\), для p-поляризации \(h=Z_0H_y\), где \(Z_0=\sqrt{\mu_0/\varepsilon_0}\). Для касательной электрической амплитуды \(E\) имеем

\[
E=E^++E^-,\qquad h=Y(E^+-E^-),
\]

где знаки \(+,-\) обозначают распространение к подложке и к источнику соответственно. Из уравнений Максвелла:

\[
Y_s=q=\widetilde n\cos\theta,\qquad
Y_p=\frac{\varepsilon}{q}=\frac{\widetilde n}{\cos\theta}.
\]

Вектор \((E,h)^T\) непрерывен на каждой границе. Выбор знаков \(h\) согласован с положительным потоком в направлении \(+z\) для прямой волны. Он учитывает разворот оси относительно книги, не меняя приведённые ниже матрицы переноса от выходной границы к входной.

## 5. Граница двух сред и рекурсия Френеля

Для волны с единичной касательной электрической амплитудой, падающей из среды \(a\) в \(b\), непрерывность \(E,h\) даёт

\[
1+f_{a,b}=g_{a,b},\qquad
Y_a(1-f_{a,b})=Y_bg_{a,b}.
\]

Отсюда

\[
\boxed{f_{a,b}=\frac{Y_a-Y_b}{Y_a+Y_b}},\qquad
\boxed{g_{a,b}=\frac{2Y_a}{Y_a+Y_b}}.
\]

Это формулы § 1.1.3, с. 18–19, после замены поляризационно зависимого \(q\) книги на \(Y\). Полезные тождества:

\[
f_{b,a}=-f_{a,b},\qquad
g_{a,b}g_{b,a}=1-f_{a,b}^{\,2}.
\]

Здесь квадрат комплексный, без сопряжения. Энергетический коэффициент отражения обозначается \(R\), а не \(f^2\).

Пусть \(b_j,\tau_j\) — отражение и пропускание части структуры справа от границы \(j|j+1\), для падения из среды \(j\). Для последней границы:

\[
b_N=f_{N,N+1},\qquad \tau_N=g_{N,N+1}.
\]

Обозначим \(u_{j+1}=e^{-i\phi_{j+1}}\), \(\phi_{j+1}=kq_{j+1}d_{j+1}\). Один проход через слой даёт \(u\), полный обход между его границами — \(u^2\). Коэффициент каждого повторного обхода равен \(f_{j+1,j}b_{j+1}u^2=-f_{j,j+1}b_{j+1}u^2\). Сумма повторных отражений даёт

\[
D_j=1+f_{j,j+1}b_{j+1}u_{j+1}^{\,2},
\]

\[
\boxed{b_j=\frac{f_{j,j+1}+b_{j+1}u_{j+1}^{\,2}}{D_j}},\qquad
\boxed{\tau_j=\frac{g_{j,j+1}u_{j+1}\tau_{j+1}}{D_j}},
\qquad j=N-1,\ldots,0.
\]

Итог: \(r_{\rm tan}=b_0\), \(t_{\rm tan}=\tau_0\). При \(N=0\) берётся сразу \(b_0=f_{0,N+1}\), \(\tau_0=g_{0,N+1}\). Обе правые части вычисляются из старых \(b_{j+1},\tau_{j+1}\); нельзя сначала заменить \(b\), а затем использовать уже обновлённое значение в знаменателе \(\tau\).

Связь с книгой прямая: в (1.2.18), с. 32, делим числитель и знаменатель на \(e^{+i\phi}\) и разворачиваем нумерацию слоёв. Инициализация соответствует (1.2.17), с. 31. Получаются только затухающие экспоненты, без вычисления растущего множителя \(e^{+i\phi}\).

Эта рекурсия хороша вдали от \(q=0\), но расчёт отдельных границ при \(q\to0\) может содержать взаимно сокращающиеся сингулярности. Особенно неудобен расходящийся \(Y_p=\varepsilon/q\). Поэтому рабочий вариант ниже объединяет обе границы и конечную толщину каждого слоя в один аналитический блок.

## 6. Характеристические матрицы и правильный порядок

Для слоя \(j\) связь полей на входной и выходной поверхностях имеет вид

\[
\begin{pmatrix}E\cr h\end{pmatrix}_{z=z_{j-1}}
=M_j
\begin{pmatrix}E\cr h\end{pmatrix}_{z=z_j},\qquad
M_j=
\begin{pmatrix}
\cos\phi_j & i\sin\phi_j/Y_j\\
iY_j\sin\phi_j & \cos\phi_j
\end{pmatrix},\qquad \det M_j=1.
\]

Это (1.2.9), с. 25, в нашей геометрии. Проверка знака: в однородной согласованной среде \(r=0\), \(t=e^{-i\phi}\).

При выбранной нумерации

\[
\boxed{M=M_1M_2\cdots M_N}.
\]

Самая правая матрица действует первой на поле у подложки. В книге (1.2.11), с. 25, записано \(M_m\cdots M_1\), поскольку слой \(m\) там обращён к внешней среде. Физически порядок один и тот же: множители слева направо следуют от внешней среды к подложке.

Пусть \(M=(m_{ab})\), \(Y_b=Y_{N+1}\). При единичной падающей амплитуде

\[
\begin{pmatrix}1+r\cr Y_0(1-r)\end{pmatrix}
=M\begin{pmatrix}t\cr Y_bt\end{pmatrix}.
\]

Вводя \(U=m_{11}+m_{12}Y_b\), \(V=m_{21}+m_{22}Y_b\), получаем

\[
\boxed{r=\frac{Y_0U-V}{Y_0U+V}},\qquad
\boxed{t=\frac{2Y_0}{Y_0U+V}}.
\]

Это (1.2.13)–(1.2.14), с. 26. Для \(N=0\) матрица единичная, что воспроизводит Френеля.

Обычные комплексные \(\sin\phi,\cos\phi\) содержат одновременно затухающие и растущие экспоненты. При большой отрицательной \(\operatorname{Im}\phi\) их модули растут экспоненциально, хотя физические \(r,t\) ограничены. Последующее вычитание близких больших чисел теряет значащие цифры. Поэтому прямое произведение \(M\) служит независимым проверочным методом для умеренных оптических толщин и хорошо обусловленных примеров, но не единственным рабочим ядром.

## 7. Рабочий метод: матрицы рассеяния с общим вещественным портом

### 7.1. Что означает фиктивный порт

Для каждой поляризации и каждого спектрального узла выбирается один положительный вещественный нормированный адмиттанс

\[
Y_{\rm ref}=Y_{\sigma,0}>0.
\]

Любой вектор касательных полей представляется в этом базисе:

\[
E=a^++a^-,\qquad h=Y_{\rm ref}(a^+-a^-).
\]

Это алгебраическая смена координат поля. Фиктивные промежутки не имеют толщины и не добавляют ни оптической фазы, ни нового материала в физическую структуру. Один и тот же \(Y_{\rm ref}\) используется на обоих концах каждого конечного слоя, так что между блоками достаточно каскадирования их матриц рассеяния. На физической входной границе \(Y_{\rm ref}=Y_0\), поэтому полученная падающая амплитуда совпадает с требуемой нормировкой.

Для однородного слоя между одинаковыми портами матрица рассеяния симметрична:

\[
\begin{pmatrix}a^-_{\rm left}\\a^+_{\rm right}\end{pmatrix}
=\begin{pmatrix}r_\ell&t_\ell\\t_\ell&r_\ell\end{pmatrix}
\begin{pmatrix}a^+_{\rm left}\\a^-_{\rm right}\end{pmatrix}.
\]

### 7.2. Формулы слоя без растущих экспонент

Положим

\[
u=e^{-ikqd},\qquad v=u^2,\qquad A=1+v,\qquad
F=\frac{1-v}{2q}.
\]

Временный символ \(A\) в этом подразделе — элемент формулы блока, а не поглощение \(A_\sigma\). Чтобы не путать их в реализации, используются отдельные имена.

Умножение характеристической матрицы на \(2u\) даёт

\[
2uM=
\begin{pmatrix}
1+u^2 &(1-u^2)/Y\\
Y(1-u^2)&1+u^2
\end{pmatrix}.
\]

После подстановки в граничные условия одинаковых портов удобно определить

\[
\begin{array}{c|cc}
&P&Q\\\hline
s&F Y_{\rm ref}&Fq^2/Y_{\rm ref}\\[2pt]
p&F Y_{\rm ref}q^2/\varepsilon&F\varepsilon/Y_{\rm ref}
\end{array}
\]

и

\[
D=A+P+Q,\qquad B=P-Q,\qquad C=A-P-Q.
\]

Тогда

\[
\boxed{r_\ell=\frac{B}{D}},\qquad
\boxed{t_\ell=\frac{2u}{D}}.
\]

В явном виде для s:

\[
D_s=1+u^2+F(q^2/Y_{\rm ref}+Y_{\rm ref}),\qquad
r_{\ell,s}=\frac{F(Y_{\rm ref}-q^2/Y_{\rm ref})}{D_s}.
\]

Для p:

\[
D_p=1+u^2+F(\varepsilon/Y_{\rm ref}+Y_{\rm ref}q^2/\varepsilon),\qquad
r_{\ell,p}=\frac{F(Y_{\rm ref}q^2/\varepsilon-\varepsilon/Y_{\rm ref})}{D_p}.
\]

Значение \(q^2\) в формулах лучше брать непосредственно как \(\varepsilon-\alpha^2\), а не повторно возводить численный корень в квадрат.

Все экспоненты затухающие. При \(|u|\to0\) элементы конечного блока имеют конечный предел; если обычное \(u\) уже округлилось к нулю, его логарифм всё ещё можно учитывать в пропускании.

### 7.3. Малые фазы и точное \(q=0\)

Прямое вычитание \(1-u^2\) теряет точность при малой фазе. Определим

\[
\operatorname{exprel}(x)=\frac{e^x-1}{x},\qquad \operatorname{exprel}(0)=1.
\]

Тогда

\[
\boxed{F=ikd\,\operatorname{exprel}(-2ikqd)}.
\]

Для малого аргумента используется \(\operatorname{expm1}\) либо ряд
\(\operatorname{exprel}(x)=1+x/2+x^2/6+x^3/24+\cdots\). Для сильного затухания применима исходная дробь \((1-u^2)/(2q)\). Выбор ветви вычисления меняет только форму оценки одной аналитической функции.

При \(q=0\) точно:

\[
u=1,\qquad F=ikd.
\]

Это не искусственная замена \(q\) малым числом, а аналитический предел конечного слоя. Он эквивалентен

\[
\frac{\sin(kqd)}{q}\longrightarrow kd.
\]

Пределы характеристических матриц:

\[
M_s(q=0)=\begin{pmatrix}1&ikd\\0&1\end{pmatrix},
\]

\[
M_p(q=0,\varepsilon\ne0)=
\begin{pmatrix}1&0\\ik\varepsilon d&1\end{pmatrix}.
\]

Таким образом, точный критический слой конечной толщины поддерживается и для s, и для p.

Если \(\varepsilon=0\) и \(\alpha=0\), при нормальном падении отношение \(q^2/\varepsilon\) определяется совместным пределом \(q^2=\varepsilon\): оно равно 1. Поэтому для p берут \(P=F Y_{\rm ref},Q=0\), и обе поляризации дают одинаковый касательный блок. Если \(\varepsilon=0\), но \(\alpha\ne0\), выражение p-поля содержит истинно сингулярный материальный предел. Такой вход должен возвращать явный статус неподдерживаемой конфигурации; подстановка произвольного малого \(\varepsilon\) не обоснована. Для малых ненулевых \(\varepsilon\) расчёт допустим, но может быть плохо обусловлен и требовать повышенной точности.

### 7.4. Завершение полубесконечной подложкой

Каскад начинается с границы \(Y_{\rm ref}|Y_{\rm sub}\):

\[
b=\frac{Y_{\rm ref}-Y_{\rm sub}}{Y_{\rm ref}+Y_{\rm sub}},\qquad
\tau=\frac{2Y_{\rm ref}}{Y_{\rm ref}+Y_{\rm sub}}.
\]

Чтобы не вычислять большой \(Y_{p,\rm sub}=\varepsilon_{\rm sub}/q_{\rm sub}\) вблизи критического угла, p-формулы записываются как

\[
b_p=\frac{Y_{\rm ref}q_{\rm sub}-\varepsilon_{\rm sub}}
{Y_{\rm ref}q_{\rm sub}+\varepsilon_{\rm sub}},\qquad
\tau_p=\frac{2Y_{\rm ref}q_{\rm sub}}
{Y_{\rm ref}q_{\rm sub}+\varepsilon_{\rm sub}}.
\]

При точном \(q_{\rm sub}=0\) используются пределы:

\[
(b_s,\tau_s)=(1,2),\qquad (b_p,\tau_p)=(-1,0),\qquad T_s=T_p=0.
\]

Ненулевой \(\tau_s\) в таком пределе не означает ненулевой нормальный поток. Аналогично не следует вычислять \(\infty\cdot|0|^2\) для p.

### 7.5. Каскадирование и детерминантная форма

Если справа от слоя имеется остаток структуры с коэффициентами \(b,\tau\), то исключение встречной волны на общей границе даёт

\[
b_{\rm new}=r_\ell+\frac{t_\ell^2 b}{1-r_\ell b},\qquad
\tau_{\rm new}=\frac{t_\ell\tau}{1-r_\ell b}.
\]

Квадрат \(t_\ell^2\) возникает из двух проходов через этот блок. Сопряжение здесь не применяется. Эта формула эквивалентна интерфейсной рекурсии § 5: каждый блок включает входную границу фиктивный порт/слой, распространение и выходную границу слой/тот же порт.

Вычислять её буквально не обязательно. Из \(PQ=F^2q^2\) и \((1+u^2)^2-(1-u^2)^2=4u^2\) следует

\[
t_\ell^2-r_\ell^2=\frac{C}{D}.
\]

Следовательно,

\[
\boxed{b_{\rm new}=\frac{B+Cb}{D-Bb}},\qquad
\boxed{\tau_{\rm new}=\frac{2u\tau}{D-Bb}}.
\]

Удобная для вычислений группировка:

\[
H=A+P(1-b)+Q(1+b),
\]

\[
\boxed{b_{\rm new}=\frac{Ab+P(1-b)-Q(1+b)}{H}},\qquad
\boxed{\tau_{\rm new}=\frac{2u\tau}{H}}.
\]

Она исключает явное вычитание \(t_\ell^2-r_\ell^2\) и деление на \(D\) на промежуточном шаге. Это не доказательство абсолютной устойчивости при любых данных: очень малый \(H\), огромные контрасты адмиттансов, почти нулевой \(\varepsilon\) или крайне большая фаза всё ещё ограничивают точность.

Слои добавляются в порядке \(j=N,N-1,\ldots,1\). При каждом шаге числитель, \(H\) и обновление пропускания используют старое \(b\). После последнего шага \(r_{\rm tan}=b\), \(t_{\rm tan}=\tau\).

### 7.6. Очень малое пропускание

Для \(\tau\ne0\) отдельно хранят \(\ell_t=\log|\tau|\) и \(\vartheta_t=\arg\tau\). Так как

\[
\log|u|=kd\operatorname{Im}q,\qquad \arg u=-kd\operatorname{Re}q\pmod{2\pi},
\]

обновление имеет вид

\[
\ell_{t,\rm new}=\ell_t+\log2+kd\operatorname{Im}q-\log|H|,
\]

\[
\vartheta_{t,\rm new}=\vartheta_t-kd\operatorname{Re}q-\arg H\pmod{2\pi}.
\]

Логарифм затухания берётся прямо из \(q\), а не как логарифм уже округлившегося к нулю \(u\). Если поток в подложку возможен,

\[
\boxed{\log T=\log\operatorname{Re}Y_{\rm sub}
-\log Y_0+2\ell_t}.
\]

Значение \(t\) или \(T\) можно восстановить, пока результат представим в выбранном формате. Если восстановление дало ноль из-за ограниченного динамического диапазона, сохраняются конечный \(\log T\) и статус потери представимости. Это отличается от физического \(T=0\) у эванесцентной или критической выходной волны. В последнем случае \(\log T=-\infty\) математически и при JSON-экспорте передаётся как `null` с соответствующим статусом.

Для критической p-подложки \(\tau=0\) физически в выбранной касательной нормировке. Её логарифмическое представление отмечается отдельным состоянием нулевой амплитуды; выражение \(\log0\) не используется как обычное конечное число.

## 8. Энергетические коэффициенты и независимый контроль потерь

В системе SI усреднённая нормальная компонента вектора Пойнтинга выражается через наши \(E,h\) как

\[
\langle S_z\rangle=\frac{1}{2Z_0}\operatorname{Re}(Eh^*).
\]

Для одной прямой волны \(h=YE\):

\[
\langle S_z^+\rangle=\frac{\operatorname{Re}Y}{2Z_0}|E^+|^2.
\]

Для обратной волны знак потока меняется. В прозрачной внешней среде \(Y_0\) действителен, интерференционные члены полного входного нормального потока взаимно сокращаются. Поэтому для каждой поляризации

\[
\boxed{R_\sigma=|r_{{\rm tan},\sigma}|^2},
\]

\[
\boxed{T_\sigma=\frac{\operatorname{Re}Y_{\sigma,N+1}}
{\operatorname{Re}Y_{\sigma,0}}|t_{{\rm tan},\sigma}|^2},
\]

\[
\boxed{A_\sigma=1-R_\sigma-T_\sigma}.
\]

Это (1.1.22)–(1.1.23), с. 21, и определение поглощения на с. 22, с учётом нашей ориентации \(z\) и системы единиц. Множитель \(1/(2Z_0)\) сокращается в отношениях. В книге при противоположной оси поток к подложке имеет отрицательный знак.

\(T\) обычно не равно \(|t|^2\), поскольку одинаковая касательная электрическая амплитуда в разных средах и при разных углах несёт разный нормальный поток.

При распространяющейся волне в прозрачной подложке \(Y_{\rm sub}\) действителен и положителен; поток сохраняется с глубиной, а \(A\) относится только к конечному покрытию. При \(q_{\rm sub}\) чисто мнимом адмиттанс также чисто мнимый и \(T=0\). Подстановка комплексного отношения \(Y_{\rm sub}/Y_0\) вместо отношения действительных частей неверна.

Упрощённая формула книги на с. 26, \(T=(q_s/q_a)|t|^2\), применима при действительных адмиттансах. Фраза на с. 27 о действительности углов в отсутствие поглощения также предполагает распространяющиеся волны. При полном внутреннем отражении отсутствие поглощения материала не обеспечивает этого условия; общая (1.1.23) остаётся корректной.

Для \(N=0\): \(A=0\), \(R+T=1\). Для прозрачного покрытия: \(R+T=1\), включая эванесцентные внутренние слои при распространяющейся выходной волне. Если выходная волна эванесцентная, то \(T=0\); равенство \(R=1\) дополнительно требует отсутствия поглощения в покрытии. У поглощающего покрытия в таком режиме \(R<1\) возможно и физически означает \(A=1-R>0\).

Нельзя искусственно обрезать \(R,T,A\) до \([0,1]\). Малые отрицательные \(A\), например порядка ошибки округления, сохраняются вместе с диагностикой. Если \(A\) получено разностью, равенство \(R+T+A=1\) тождественно и не является независимым тестом.

Независимая проверка для поглощающего примера основана на локальной мощности потерь:

\[
Q_{\rm loss}(z)=\frac{\omega\varepsilon_0}{2}
[-\operatorname{Im}\varepsilon(z)]|\mathbf E(z)|^2.
\]

При падающей касательной амплитуде 1 интегральное поглощение

\[
A_{\rm field}=\frac{k}{Y_0}\sum_j
\int_{z_{j-1}}^{z_j}[-\operatorname{Im}\varepsilon_j]
|\mathbf E(z)|^2\,dz.
\]

Для s \(|\mathbf E|^2=|E_y|^2\). Для p необходимо учитывать обе компоненты: \(E_x=E^++E^-\), \(E_z=-(\alpha/q)(E^+-E^-)\); использование только касательного \(|E_x|^2\) занизит потери. У критического слоя поле получают через предельную форму, не прямым делением на \(q=0\). Другой независимый контроль — разность нормальных потоков на границах каждого слоя, вычисленных по восстановленным полям. Сумма этих потерь сравнивается с \(1-R-T\).

## 9. Спектральные данные и валидация

Перед расчётом проверяются:

1. \(N\) — целое неотрицательное; числа толщин и моделей слоёв согласованы; все \(d_j\geq0\) конечны; единица длины известна.
2. \(0\leq\theta_0<90^\circ\), единица угла указана; внутреннее значение в радианах.
3. \(0<k_1<k_2\); сетка содержит не меньше двух конечных положительных узлов, оба конца включены. Переданная явная сетка строго возрастает. Повторы, неупорядоченные значения и NaN/Inf отклоняются с понятной ошибкой. Молчаливая сортировка меняет соответствие данных и поэтому не выполняется.
4. Тип координаты отличает \(k\) от \(\bar\nu\); преобразования материалов и расчётной сетки согласованы.
5. Внешний и подложечный показатели действительны и положительны. Физически ненулевая мнимая часть подложки недопустима. Её нельзя молча отбросить.
6. Для слоя явно задано соглашение комплексного показателя. Данные вида \(n+i\kappa\) переводятся в \(n-i\kappa\) сопряжением при загрузке; знак нельзя угадывать по части строк таблицы. Затем проверяется пассивность и конечность всех значений.
7. Спектральный диапазон находится внутри области определения каждого материала. Экстраполяция запрещена по умолчанию и не выполняется без отдельного явно задокументированного решения.

Для табличных данных координаты сначала приводят к общему типу и единицам. Если таблица задана по длине волны, преобразование к \(k\) меняет порядок узлов; загрузчик обязан согласованно переставить и координаты, и значения материала. Это обработка формата таблицы, а не молчаливая сортировка уже заданной расчётной сетки.

Для слоёв интерполируют действительную часть \(n\) и неотрицательную \(\kappa\) раздельно, после чего строят комплексный показатель. Линейная интерполяция сохраняет неотрицательность значений между узлами; более гладкая интерполяция допустима при контроле выбросов и пассивности. Для подложки интерполируют только действительный положительный \(n_{\rm sub}\). Нельзя интерполировать угол комплексного показателя или выбирать знак мнимой части после интерполяции произвольно.

Для функции материала договором задаётся пассивность и корректность на всём интервале. Численный расчёт проверяет фактически вычисленные узлы, а не доказывает свойства произвольной функции между ними. Табличный линейный интерполятор с корректными исходными \(n,\kappa\) обеспечивает указанные знаковые условия и между узлами. Никакие справочные значения реальных материалов в ядро не подставляются автоматически.

Физическое ядро получает уже вычисленные массивы оптических констант. Чтение файлов, выбор интерполятора, экспорт, интерфейс и визуализация должны находиться вне него.

## 10. Эллипсометрические базисы, отношение и углы

### 10.1. Знак p-отражения

Для падающей и отражённой волн явно фиксируются единичные векторы

\[
\mathbf e_{p,\rm in}=(\cos\theta_0,0,-\sin\theta_0),\qquad
\mathbf e_{p,\rm refl}=(-\cos\theta_0,0,-\sin\theta_0),
\]

\[
\mathbf e_{s,\rm in}=\mathbf e_{s,\rm refl}=(0,1,0).
\]

Касательные x-компоненты двух p-базисов имеют противоположные знаки. Поэтому амплитудные коэффициенты в этих базисах равны

\[
\boxed{r_s=r_{{\rm tan},s}},\qquad
\boxed{r_p=-r_{{\rm tan},p}}.
\]

Это согласуется с замечанием о знаке p-отражения в книге, с. 19. Для энергии знак несущественен, а для эллипсометрической фазы существенен.

Определение данного пакета:

\[
\boxed{\rho=\frac{r_p}{r_s}=\tan\Psi\,e^{i\Delta}}.
\]

Выбранное соглашение не единственно возможное. Если поменять знак только отражённого p-базиса, \(\rho\) поменяет знак, а \(\Delta\) сдвинется на \(\pi\); \(R_s,R_p,T_s,T_p,\Psi\) останутся прежними. Сравнение фаз разных программ требует совпадения базисов, временного множителя, определения \(\rho\) и плоскостей отсчёта.

### 10.2. Вычисления и неопределённые случаи

При ненулевых отражённых компонентах

\[
\boxed{\Psi=\operatorname{atan2}(|r_p|,|r_s|)},\qquad 0\leq\Psi\leq\pi/2,
\]

\[
\boxed{\Delta=(\arg r_p-\arg r_s)\bmod 2\pi},\qquad 0\leq\Delta<2\pi.
\]

Выражение \(\arg(r_pr_s^*)\) математически эквивалентно, но произведение очень малых чисел может потерять представимость. Вычитание аргументов либо произведение предварительно нормированных фазовых множителей избегает этого. Аналогично \(\rho\) вычисляют делением комплексных чисел с контролем масштаба, а не через деление интенсивностей и восстановление произвольной фазы.

В результате возвращают радианы и отдельно обозначенные градусы: \(\Psi_{\rm deg}=180\Psi/\pi\), \(\Delta_{\rm deg}=180\Delta/\pi\).

| Случай | \(\rho\) | \(\Psi\) | \(\Delta\) |
|---|---|---|---|
| \(r_s\ne0,r_p\ne0\) | Конечное отношение | Определена | Определена |
| \(r_s\ne0,r_p=0\) | 0 | 0 | Не определена |
| \(r_s=0,r_p\ne0\) | Сингулярно; не конечное комплексное число | \(\pi/2\) | Не определена |
| \(r_s=r_p=0\) | Не определено | Не определена | Не определена |

Эталонное ядро использует один настраиваемый абсолютный порог модуля отражённой амплитуды:

\[
\eta=\texttt{ellipsometry\_atol},\qquad \eta_{\rm default}=10^{-12}.
\]

В области \(|r_\sigma|\leq\eta\) фаза соответствующей компоненты считается ненадёжной. Относительный порог в текущем интерфейсе не реализован. Для отношения достаточна достоверная ненулевая s-компонента; численное малое p-отражение само по себе не делает деление неопределённым, но ограничивает относительную точность результата. Для \(\Psi\) достаточно \(\max(|r_s|,|r_p|)>\eta\). Для \(\Delta\) нужны обе достоверные компоненты: \(\min(|r_s|,|r_p|)>\eta\).

Неопределённые значения не заменяют нулевой фазой. Возвращаются значения/пустые поля, отдельные маски достоверности и общее сообщение `ELLIPSOMETRY_UNDEFINED`; конкретное численное состояние определяется по амплитудам и маскам. Арифметика float64 сама по себе не доказывает, что близкая к нулю или округлившаяся к нулю амплитуда является точным математическим нулём. Таблица выше описывает аналитические случаи, а реализованные маски — достоверность численного результата относительно выбранного порога. Порог, временное соглашение и базисы входят в метаданные результата.

Развёртку \(\Delta\) выполняют только на отдельных непрерывных участках достоверных узлов. Через пропущенную точку с нулевым отражением непрерывность фазы не предполагается. Редкая сетка с изменением фазы более чем на \(\pi\) между соседними узлами может сделать развёртку неоднозначной даже при достоверных значениях в самих узлах.

### 10.3. Нормальное падение и смена временного соглашения

При \(\theta_0=0\) обе касательные задачи совпадают: \(Y_s=Y_p=\widetilde n\), поэтому

\[
R_s=R_p,\qquad T_s=T_p,\qquad r_p=-r_s.
\]

При ненулевом отражении \(\rho=-1\), \(\Psi=45^\circ\), \(\Delta=180^\circ\). При отсутствии отражения углы не определены. Геометрическая плоскость падения при нормальном падении вырождена; выбранные направления \(x,y\) остаются соглашением координат.

Экспорт в \(e^{-i\omega t}\), \(n+i\kappa\), при сохранении тех же пространственных базисов и определения отношения, выполняется комплексным сопряжением:

\[
r_{\rm tan}'=r_{\rm tan}^*,\quad t_{\rm tan}'=t_{\rm tan}^*,\quad
r_s'=r_s^*,\quad r_p'=r_p^*,\quad\rho'=\rho^*.
\]

\[
R'=R,\quad T'=T,\quad A'=A,\quad\Psi'=\Psi,\quad
\Delta'=(-\Delta)\bmod2\pi.
\]

Это та же физическая волна в другой записи, а не замена поглощения усилением. При независимом перерасчёте в новом временном соглашении необходимо менять и пространственные экспоненты, и ветвь затухания, а не только знак входной \(\kappa\).

## 11. Полный псевдокод ядра

Псевдокод описывает математические операции; его имена не заменяют фактическую спецификацию программного интерфейса.

```text
ВХОД:
    тип спектральной координаты и единицы;
    возрастающая сетка M узлов [k1, k2];
    угол падения и единица угла;
    толщины N слоёв с единицей длины;
    прозрачные модели n0 и n_sub;
    пассивные модели n_j - i*kappa_j;
    численные допуски, пороги достоверности, правила диагностики.

ПРОВЕРИТЬ вход, привести длины и координаты к внутренним единицам.
УДАЛИТЬ конечные слои нулевой толщины до делений на q или epsilon.

ДЛЯ каждого спектрального узла:
    k := угловое вакуумное волновое число
    lambda_vac := 2*pi/k
    вычислить n0, n_sub и комплексные n_j на данном узле
    проверить конечность, прозрачность граничных сред, пассивность слоёв
    alpha := n0*sin(theta0)
    q0 := n0*cos(theta0)
    epsilon_j := n_j**2
    q2_j := менее чувствительная к округлению форма:
            epsilon_j - alpha**2 либо (n_j-n0)*(n_j+n0)+q0**2;
            применить явно заданный режим critical_roundoff
    q_j := физическая ветвь sqrt(q2_j)
    q_sub := физическая ветвь sqrt(n_sub**2 - alpha**2)

    ДЛЯ sigma в [s, p]:
        Yref := q0 для s; n0**2/q0 для p
        (b, tau_terminal) := Френель порт/подложка,
                             с явным пределом при q_sub == 0
        если tau_terminal != 0:
            log_abs_t := log(abs(tau_terminal))
            phase_t := arg(tau_terminal)
            amplitude_zero := false
        иначе:
            amplitude_zero := true

        ДЛЯ j = N, N-1, ..., 1:
            phi := k*q_j*d_j
            u := exp(Im(phi)) * exp(-i*Re(phi))
            Ablock := 1 + u*u
            F := аналитическая функция (1-u*u)/(2*q_j),
                 вычисленная через exprel при малой фазе;
                 при q_j == 0: F := i*k*d_j

            если sigma == s:
                P := F*Yref
                Q := F*q2_j/Yref
            иначе:
                если epsilon_j == 0 и alpha != 0:
                    вернуть явную диагностику неподдерживаемого p-предела
                ratio := q2_j/epsilon_j,
                         либо 1 при epsilon_j == 0 и alpha == 0
                P := F*Yref*ratio
                Q := F*epsilon_j/Yref

            b_old := b
            H := Ablock + P*(1-b_old) + Q*(1+b_old)
            проверить конечность H и оценить его малость относительно слагаемых
            numerator := Ablock*b_old + P*(1-b_old) - Q*(1+b_old)
            b := numerator/H

            если amplitude_zero == false:
                log_abs_t += log(2) + Im(phi) - log(abs(H))
                phase_t := (phase_t - Re(phi) - arg(H)) modulo 2*pi

        r_tan_sigma := b
        t_tan_sigma := 0, если amplitude_zero,
                       иначе exp(log_abs_t)*exp(i*phase_t), если представимо
        R_sigma := abs(r_tan_sigma)**2

        если q_sub == 0 или выходная волна эванесцентна:
            T_sigma := 0
            log_T_sigma := физический нулевой поток
        иначе:
            Ysub := q_sub для s; n_sub**2/q_sub для p
            log_T_sigma := log(Ysub) - log(Yref) + 2*log_abs_t
            T_sigma := exp(log_T_sigma), если представимо
            если положительное значение потеряло представимость:
                T_sigma := 0; добавить соответствующий статус

        A_sigma := 1 - R_sigma - T_sigma
        сохранить исходные значения без обрезания
        добавить диагностику нарушения ожидаемых энергетических границ

    r_s := r_tan_s
    r_p := -r_tan_p
    вычислить маски отражения, rho, Psi и Delta согласно § 10
    сохранить результат и диагностику узла

ПОСЛЕ цикла:
    при запросе развернуть Delta отдельно на достоверных непрерывных участках
    записать единицы, соглашения, пороги и алгоритм в метаданные
    экспортировать комплексные числа как {re, im};
    неопределённые/непредставимые числа как null со статусом.
```

При \(N=0\) внутренний цикл пуст, и инициализация сразу возвращает Френеля. Совпадающие соседние материалы не требуют специальной физической обработки; объединение таких слоёв с суммированием толщин допустимо как оптимизация, если их дисперсионные модели действительно идентичны на всём интервале.

## 12. Разрешение спектра, вычислительная сложность и пределы точности

Расчёт на заданной сетке и доказательство достаточности этой сетки — разные задачи. Все параметры материала, \(\alpha\), \(q\), фазовые толщины и адмиттансы пересчитываются на каждом узле. Постоянство угла падения не означает постоянство \(\alpha\), если внешняя среда имеет дисперсию.

Практический контроль разрешения:

1. Рассчитать заданную сетку и отдельно значения в серединах её интервалов.
2. Сравнить результат в новых узлах с интерполяцией результатов грубой сетки для \(R,T\) и комплексных \(r_s,r_p\). Сравнение только в старых совпадающих узлах бессодержательно: точечное ядро даст те же числа.
3. Проверять абсолютную и относительную невязку, например \(|f_{\rm fine}-f_{\rm interp}|\leq a+r|f_{\rm fine}|\), где допуски выбираются под задачу. Для фаз использовать комплексные амплитуды либо расстояние фазовых множителей, не линейную интерполяцию обёрнутой \(\Delta\).
4. Уточнять интервалы с превышением допуска, быстрой фазой или изменением достоверности. Ограничить число узлов и итераций; при исчерпании бюджета вернуть статус недостигнутой сходимости.

Такая проверка оценивает обнаруженные особенности. Она не гарантирует обнаружение любого узкого резонанса, расположенного между редкими пробами. Для фильтров с высокой добротностью нужны физически обоснованная начальная сетка, поиск резонансов или более строгие адаптивные методы. Развёртка фазы не исправляет недостаточное разрешение.

Время ядра — \(O(NM)\); дополнительные расходы зависят от моделей материалов и адаптивной сетки. Для поточечного расчёта рабочая память — \(O(N)\), либо \(O(1)\) сверх входа при последовательном доступе к слоям; сохранение всех спектральных выходов требует \(O(M)\). Полная материализация таблицы всех слоёв на всех узлах требует \(O(NM)\) памяти. Векторизация по спектру может ускорить вычисления, но не меняет асимптотику.

Базовая арифметика — вещественная/комплексная двойной точности. Существенные ограничения:

- Очень большой \(|\operatorname{Re}\phi|\) ограничивает точность фаз. Ошибка входного \(n\), толщины или произведения \(kqd\) превращается в фазовую ошибку; простой перевод фазы по модулю \(2\pi\) не восстанавливает потерянные цифры.
- Около узкого резонанса относительная точность малого знаменателя \(H\) может быть недостаточна. Следует сравнивать \(|H|\) с суммой модулей его слагаемых и выдавать диагностику; при необходимости пересчитывать с повышенной точностью.
- При \(\theta_0\to90^\circ\) падающий нормальный поток стремится к нулю. s- и p-адмиттансы имеют разные пределы, а нормировка потоков становится чувствительной. Точное скользящее падение исключено из входа.
- При \(\varepsilon-\alpha^2\approx0\) возникают потери значащих цифр в исходном вычитании. Аналитический блок устраняет сингулярность формул, но не восстанавливает неизвестные значащие цифры параметров.
- Большие контрасты индексов, очень малое ненулевое \(\varepsilon\), переполнение промежуточных алгебраических произведений и накопление ошибки при огромном \(N\) требуют контроля масштаба и иногда более высокой точности.
- При \(A\ll1\) вычисление \(1-R-T\) имеет большую относительную ошибку. Для точного малого поглощения нужен независимый расчёт по полям.
- При \(|r_s|\) или \(|r_p|\to0\) относительная ошибка фазы и эллипсометрического отношения растёт независимо от устойчивости расчёта энергии.

Численная диагностика должна различать некорректный вход, физический ноль, неопределённую фазу, потерю представимости, плохо обусловленную точку и неподдерживаемый физический предел. Дополнительная точность полезна только тогда, когда исходные оптические константы и толщины известны достаточно точно.

## 13. Контрольные случаи для реализации

Ниже перечислены ожидаемые физические свойства. Факт выполнения тестов и полученные невязки следует брать из фактического отчёта запуска тестов, а не из этого теоретического раздела.

| Проверка | Ожидаемый результат |
|---|---|
| \(N=0\), нормальное и наклонное падение | Аналитические коэффициенты Френеля, \(A=0\) |
| Поглощающий показатель подложки | Явное отклонение входных данных |
| Один конечный слой | Совпадение с независимой формулой Эйри |
| \(n_1=\sqrt{n_0n_{\rm sub}}\), \(n_1d=\lambda/4\), нормальное падение | Нулевое отражение в расчётной точке с учётом округления; эллипсометрия не определена при обоих нулях |
| Прозрачные материалы | \(R_s+T_s=R_p+T_p=1\) |
| Прозрачный эванесцентный внутренний слой и распространяющийся выход | Туннельное пропускание возможно; энергетический баланс сохраняется |

| Полное внутреннее отражение без потерь | \(R=1,T=0\) |
| Точный критический выход и точный критический конечный слой | Корректные аналитические пределы без подстановки малого \(q\) |
| Поглощающий слой при эванесцентном выходе | \(T=0\), \(A=1-R\geq0\) в пределах ошибки |
| Поглощающий пример с восстановленными полями | Совпадение \(1-R-T\) с интегралом потерь либо суммой разностей потоков |
| Удаление слоя нулевой толщины | Все амплитуды и энергии неизменны |
| Разбиение слоя на два одинаковых | Все амплитуды и энергии неизменны при сохранении суммарной толщины |
| Очень толстый поглощающий первый слой | \(T\to0\); \(r\) стремится к Френелю для полубесконечного материала первого слоя; нет растущих экспонент |

| Эквивалентные входы \(k\), \(\bar\nu\) и единицы длины | Одинаковые фазы и спектры |

Для хорошо обусловленных синтетических случаев двойной точности разумный ориентир амплитудного абсолютного допуска — \(10^{-12}\)–\(10^{-10}\), относительного — \(10^{-10}\); конкретный тест должен учитывать масштаб и накопление ошибки. Для энергии около нуля нужен абсолютный допуск. Для фазы допуск применим только при достоверных ненулевых амплитудах. Вблизи резонансов или предельных материальных параметров фиксированный допуск без оценки обусловленности не обоснован.
